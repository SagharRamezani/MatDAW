# MatDAW

Design and implementation of the signal-processing engine of a Digital Audio Workstation (DAW) in MATLAB.

## Project Overview

This project applies Signals and Systems concepts to audio processing in four phases:

1. Triangle-wave synthesis using Fourier series
2. Voice recording, resampling, and anti-aliasing
3. Audio mixing and echo using FIR and IIR systems
4. Three-band digital equalizer and Z-plane analysis

## Technologies

- MATLAB
- Signal Processing Toolbox
- Audio processing
- Fourier analysis
- Digital filtering
- Sampling and resampling
- LTI systems
- Z-transform
